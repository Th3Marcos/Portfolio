# 🚀 Portfólio Pessoal

Portfólio web desenvolvido para centralizar e apresentar meus principais projetos de front-end, destacando minha evolução e habilidades no desenvolvimento web.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e organizada do conteúdo.
* **CSS3:** Estilização moderna, efeitos de transição, rolagem suave (*smooth scroll*) e design responsivo.
* **Git e GitHub:** Controle de versão e hospedagem via GitHub Pages.

---

## 📌 Principais Projetos Exibidos

* **Startech Car Service:** Landing page responsiva para serviços automotivos.
* **Cadastro de Usuário:** Interface moderna com efeito glassmorphism e Dark/Light Mode.
* **Desafios Sociais:** Página voltada para projetos e desafios de impacto social.
* **Projeto Cordel:** Página estilizada com efeito parallax inspirada na literatura nordestina.
